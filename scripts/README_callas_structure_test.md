# Тест структуры файлов через Callas Toolbox

Скрипт `test_callas_structure_report.py` проверяет каждый входной файл и создаёт:

- `callas_structure_report.pdf` — многостраничный отчёт, по странице на файл;
- `results.json` — те же результаты в машиночитаемом виде;
- `callas-output/` — PDF, созданные Callas из растровых входных файлов.

Растровые файлы сначала обрабатываются Callas командой `--topdf`; созданная
копия сохраняется в `callas-output/`. До конвертации фиксируются формат, список
каналов, наличие альфа-канала, наличие несведённых TIFF/PSD-слоёв и число
страниц/кадров. Исходные файлы не перезаписываются.

```bash
.venv/bin/python scripts/test_callas_structure_report.py "/путь/к/тестовым-файлам" \
  --cli "/путь/к/pdfToolbox" \
  --cache "/путь/к/.callas-cache" \
  --output "/путь/к/результату"
```

Если нужно проверить только распознавание структуры без запуска Callas:

```bash
.venv/bin/python scripts/test_callas_structure_report.py "/путь/к/файлу.tiff" --no-callas
```

Для PDF скрипт не выполняет повторную конвертацию, а отмечает его как исходный
PDF. Для растровых файлов Callas запускается с `--topdf`; код ошибки и текст
ошибки попадают в PDF и JSON-отчёт. `--no-callas` отключает обработку только
для отдельной диагностической проверки ImageMagick.

# Итоговые PDF и исправленные ревизии

- `passed` → `PDF/Print`: все включённые обязательные проверки завершены без замечаний.
- `warning` → `PDF/Rework`: PDF читается, но локальная проверка или PitStop нашла замечания, включая ошибки preflight. Исходные ошибки сохраняются в отчёте.
- `error` → `PDF/Failed`: ошибка сборки, чтения или выполнения обязательной проверки. Если результат создать невозможно, папка может оставаться пустой.

После локальных замечаний собирается диагностический PDF без исправления масштаба и разрешения. Если он читается, PitStop запускается в том же прогоне. Нечитаемые файлы сопровождаются `pitstop_skipped_reason`. Диагностический результат с замечаниями попадает в Rework; технический сбой проверки — в Failed.

Принятие корректировки Callas повторно проверяет фактические размеры, страницы, DPI и цветовые модели PDF, затем запускает настроенный PitStop, создаёт превью новой ревизии и обновляет статус. Для исправленного результата `revision_check` содержит текущие локальные замечания; исходные списки относятся к исходным файлам. Данные красочности предыдущего PDF сбрасываются в `not_checked`. Исходные изображения не изменяются.

Смена статуса сохраняет имя итогового PDF и убирает предыдущую копию из прежней папки. Новая копия и резервные файлы готовятся вне папок статусов. Ошибка финальной публикации или сохранения данных ревизии оставляет последнюю сохранённую ревизию и её статус. Принятие исправления сериализовано с отправкой заказа в печать/возвратом.

Кнопка оператора «в печать» не отменяет замечания: `warning`/`error` нельзя перенести в Print. Изменение уже проверенного PDF обнаруживается по SHA-256 и вызывает повторную проверку перед печатью.

Проверено локально: полные Python-тесты; реальные ImageMagick/Ghostscript при сборке растрового диагностического PDF и контрольном рендере; фейки PitStop и Callas для повторных исправлений и сбоев сохранения. Живые PitStop/Callas не вызывались, production не перезапускался.

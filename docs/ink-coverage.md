# Красочность callas

Проверка включается отдельно: `IMAGE_MAGIC_CALLAS_INKCOVERAGE_ENABLED=true`.
Подключение и общая папка используют существующие настройки callas. По умолчанию
проверка выключена; отсутствие данных не создаёт флаги «Недолив»/«Перелив».

Пределы задаются в `PrePressProfile.ink_min_percent` / `ink_max_percent` или через
`IMAGE_MAGIC_INK_MIN_PERCENT` / `IMAGE_MAGIC_INK_MAX_PERCENT`. По умолчанию оба
предела отсутствуют: 20% и 250% — примеры для тестов интерфейса, а не нормативы.
Можно настроить только один предел. Значения должны быть конечными,
неотрицательными, минимум не может превышать максимум.

`order.ink_coverage` хранит `status`, `resolution`, `box`, `document`, `pages`,
`flags`, `thresholds`, `error`. Страница содержит номер, список красок с именем,
типом и процентом, суммы триадных и всех красок. Минимум и максимум документа —
минимальная и максимальная сумма средних покрытий среди проверенных страниц,
с номерами страниц. Это **среднее покрытие по выбранной рамке, не TAC**
(максимальная сумма красок в отдельной точке). Проверка не заменяет проверку TAC.

Флаги выводятся только по успешно полученным измерениям и настроенным пределам;
пока они не изменяют общий статус заказа. Сбой службы сохраняется как `failed`
и не прерывает обработку. Карточка показывает компактную пиктограмму, процент,
порог и страницу в подсказке, а подробности — по отдельным страницам.

Проверено синтетическими ответами `httpx.MockTransport`, тестами разбора,
порогов, DTO и компонентов Vue. В этом продолжении сессии живая служба callas
не вызывалась. Папки успешно завершённых заданий удаляются после разбора;
при ошибке сохраняются, поскольку удалённое задание ещё может выполняться.
